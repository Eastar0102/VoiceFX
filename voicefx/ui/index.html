단축키 맵

사용 중 비어 있음 (클릭해서 지정) 주의: Windows·Discord 단축키와 겹침 사용 불가 (글자·숫자 키는 수정키와 함께)

지정된 단축키

Discord 설정 안내

  1. 사용자 설정 → 음성 및 비디오 → 입력 장치를 Default로 둡니다 (자동 전환이 꺼져 있으면 CABLE Output 선택)
  2. 소음 억제(음성 격리)를 없음으로 끕니다 — 켜두면 로봇·무전기 같은 효과와 사운드보드 소리를 잡음으로 지워버립니다. 잡음 제거는 위의 VoiceFX 소음 억제가 대신합니다
  3. 에코 제거, 자동 게인 조절도 끄면 효과가 더 깔끔하게 전달됩니다
